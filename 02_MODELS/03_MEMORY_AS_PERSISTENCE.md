# Memory as structural persistence

## Working definition

For this project, memory means a system state that persists sufficiently long to influence a later process.

DNA sequence is a physical state of the molecule that can be copied and transmitted. This does not mean every persistent molecular feature is genetic information.

## Layers of persistence

### M1 — chemical persistence
Stable covalent structure of the molecule.

### M2 — sequence persistence
Order of bases along a strand.

### M3 — paired persistence
Complementary information distributed across two strands.

### M4 — chromatin/context persistence
Higher-order organization that can affect accessibility and regulation.

### M5 — lineage persistence
Information surviving replication and transmission across generations.

## Maintenance

Persistence is not passive. Replication copies sequence; repair can restore or alter damaged structure; cellular systems regulate access and processing.

Therefore the useful architecture is:

`state → disturbance → detection/process → correction or copying → new state`

## Key distinction

A stored state and the mechanism that preserves it are different objects. Treating them as one "memory node" hides the causal structure.

## Research question

Can the distinction between stored state and maintenance process improve models of mutation, replication fidelity or repair without merely renaming established biology?

## Status

Working model. No claim of a new biological mechanism.
