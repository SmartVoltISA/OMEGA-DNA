# OMEGA-DNA Research Protocol

## Rule

Separate observation from interpretation.

## Required record for every experiment

1. HYP-ID
2. Experiment ID
3. Version/commit
4. Research question
5. Hypothesis
6. Null hypothesis / baseline
7. Input data and provenance
8. Model and assumptions
9. Parameters fixed before execution
10. Metrics
11. Acceptance/falsification criteria
12. Result
13. Reproducibility information
14. Limitations
15. Next test

## Controls

- Negative control validates the method and detects false structure.
- Positive control is permitted when an expected effect is already independently established.
- Multiple testing must be declared before analysis and corrected when appropriate.

## Reproducibility levels

- **L1:** bitwise reproducible.
- **L2:** reproducible within predefined numerical tolerance.
- **L3:** reproducible across declared hardware/OS environments.

## Boundary rule

`boundary → deviation → check → feedback → correction → new stable state`

This is a research heuristic. It must not be presented as a biological law without evidence.
