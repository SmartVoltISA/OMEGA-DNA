# OMEGA-DNA — Scientific Sources

The repository uses external sources for established molecular facts. Interpretations and hypotheses are kept separate.

## Core references

1. NCBI Bookshelf — *Biochemistry, DNA Structure*.
   https://www.ncbi.nlm.nih.gov/books/NBK538241/

2. NCBI Bookshelf — *The Structure and Function of DNA*, Molecular Biology of the Cell.
   https://www.ncbi.nlm.nih.gov/books/NBK26821/

3. NCBI Bookshelf — *DNA Replication Mechanisms*, Molecular Biology of the Cell.
   https://www.ncbi.nlm.nih.gov/books/NBK26850/

4. NHGRI — *Talking Glossary of Genetic Terms*.
   https://www.genome.gov/genetics-glossary

5. NCBI Bookshelf — *The Human Genome*.
   https://www.ncbi.nlm.nih.gov/books/NBK21134/

## Source discipline

- Use authoritative sources for established biology.
- Prefer primary research when a specific mechanistic claim is being tested.
- Record the source version/date when practical.
- Do not cite a source as evidence for a model-derived conclusion unless the source actually supports that conclusion.
- Distinguish established fact, interpretation, hypothesis, and experimental result.
