# OMEGA-DNA Remaining Execution Roadmap — 2026-09-07

Priority is empirical discrimination, not adding synthetic layers indefinitely.

## P0 — close the real biological gate
- Qualifying public multimodal dataset.
- Assembly and coordinate audit.
- Independent label provenance.
- Capacity-matched sequence baseline.
- Typed relational model.
- Chromosome-level holdout.
- Train+test relation-shuffled null.
- Label-shuffled null.
- Effect size + uncertainty + robustness.

## P1 — if E6 payload is incomplete
- Complete chunked FASTA extraction.
- Build compact candidate table from public processed assays.
- Record exact accession/assay/sample provenance.
- Keep missing modalities explicitly UNKNOWN rather than imputing biological meaning.

## P2 — additional architecture branches
Only after P0/P1 are executed or demonstrably blocked:
- transcription initiation/elongation;
- splicing/isoform relations;
- translation/coding → protein output;
- recombination/crossover;
- chromosome segregation;
- transposable-element dynamics;
- mitochondrial genome architecture;
- haplotype/sex-chromosome architecture;
- developmental state transitions;
- provenance/conflict graph;
- graph compression/identifiability;
- biological causal necessity/sufficiency.

## Stop rule
If a new synthetic experiment does not distinguish two competing explanations, it should not outrank the real-data gate in priority.
