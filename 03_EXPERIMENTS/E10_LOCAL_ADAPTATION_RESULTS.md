# E10 — Local Adaptation Without Target Labels

**Status:** exploratory negative/limited result; not preregistered.  
**Date:** 2026-10-17  
**Runner:** [E10_LOCAL_ADAPTATION_RUNNER.py](E10_LOCAL_ADAPTATION_RUNNER.py)

## Question
Can a network starting from random topology preserve an initially balanced binary pattern when it rewires using only current local states, without access to target labels?

## Protocol
- 80 nodes; 8 initial neighbors selected per node before symmetrization.
- 250 update steps; 40 seeds per cell.
- Initial state corruption: 15%; state-noise rates: 0%, 1%, and 3% per node per step.
- Conditions: static random graph (0 rewiring attempts per step) and state-based assortative rewiring (8, 32, or 80 swap attempts per step).
- A successful rewiring swap replaces two cross-state edges with two same-state edges, using only current states. Every accepted double-edge swap preserves the degree of each node exactly.
- Update rule: local majority; ties preserve the current state.
- Metric: fraction matching the initial target labels, averaged across 250 steps. Target labels are used only to score results, not to update states or select edges.
- Total: 4 × 3 × 40 = 480 trials. Approximate paired 95% confidence intervals compare each rewiring level with the static condition at the same noise rate.

## Interpretation
Under this particular local-majority rule, the system usually converges rapidly toward a single global state. Since the initial target is balanced, global consensus matches only about half of the target labels. State-based rewiring did not reliably preserve the two-class identity. The strongest rewiring setting produced a modest improvement at 0–1% noise, but this effect weakened and was not clearly different from baseline at 3% noise.

This is a useful negative result: **local adaptation and degree-preserving rewiring alone did not produce robust structural memory in this setup.** It does not disprove all possible self-organization mechanisms; it falsifies only the expectation that this particular rule is sufficient.

## Limitations
- Exploratory parameter selection; no preregistration.
- The local rule is simple and may favor global consensus.
- The graph starts random, but the initial binary pattern exists in node states; this is not spontaneous creation of information from nothing.
- No energy/resource accounting, delays, multi-state nodes, or independent implementation audit.
- The raw CSV is generated by the runner but has not been committed to the repository.

## Next test
Test a different preregistered rule that separates state persistence from consensus—for example, a local memory/hysteresis term with a fixed resource budget—and compare it against a matched no-memory control. Do not tune parameters after seeing outcomes without labeling the follow-up as exploratory.
