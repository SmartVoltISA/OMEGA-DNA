# E13 — Emergence Test Without Target Labels

**Status:** exploratory; not preregistered.  
**Date:** 2026-10-17  
**Runner:** [E13_EMERGENCE_RUNNER.py](E13_EMERGENCE_RUNNER.py)

## Question
Can local state-based rewiring preserve a differentiated binary organization when neither the graph nor the controller is given target labels?

## Protocol
- 80 binary nodes; random initial state assignment; random graph with 8 neighbors sampled per node before symmetrization.
- 200 synchronous update steps; 40 seeds per condition; 0%, 1%, and 3% independent state-flip noise per node per step.
- Four conditions: static random graph; adaptive assortative rewiring using current endpoint states; a negative control that shuffles states used by the rewiring rule; and random degree-preserving edge rewiring.
- Rewiring budget: 100 attempted edge swaps per step for each rewiring condition. Accepted double-edge swaps preserve each node's degree exactly.
- State update: local majority of neighbors; ties preserve current state.
- No target labels are generated. Metrics are minority-state fraction, binary entropy, state assortativity, time to consensus, and accepted swaps.
- Total: 3 noise levels × 4 conditions × 40 replicates = 480 trials.
- Results were evaluated in a local analysis session using the same algorithm as the committed runner. Run the runner in a clean environment to independently reproduce the raw CSV.

Minority fractions are averages over the full 200-step trajectory. At 0% noise, adaptive rewiring versus static had a paired mean minority-fraction difference of +3.16 percentage points (approximate 95% CI: -0.28 to +6.59 pp). At 1% noise the difference was +1.06 pp (CI -0.75 to +2.86 pp). At 3% noise the difference was +0.11 pp (CI +0.05 to +0.18 pp), but the final entropy was still zero and consensus occurred in every trial. The tiny 3% difference reflects transient minority states, not stable organization.

## Interpretation
**The hypothesized robust emergence of a persistent multi-state organization was not observed.** Local majority dynamics usually collapsed to global consensus within 3–4 steps. State-based assortative rewiring slightly delayed consensus in some runs at low noise but did not preserve a stable differentiated organization, and the effect disappeared at higher noise.

This is a meaningful negative result for this specific rule set. It does not disprove all possible self-organization mechanisms. It shows that local majority plus the tested rewiring rule, under the tested update order and budget, is insufficient.

## Limitations
- Exploratory and not preregistered.
- Initial binary states are random; there is no target pattern, but two possible states are part of the model by design.
- A synchronous local-majority rule strongly favors consensus and may suppress alternative forms of organization.
- No resource/energy accounting beyond a fixed number of attempted swaps.
- No delayed updates, multi-state dynamics, memory term, or independent implementation audit.
- The raw CSV is generated by the runner but has not been committed to the repository.

## Decision
**Do not accept the broad emergence hypothesis based on E13.** Record a limited negative result: this specific local majority + rewiring mechanism does not sustain differentiated organization without target labels.

## Next experiment
Before E14, preregister an alternative dynamical rule that does not trivially force consensus, justify it independently of E13 outcomes, and compare it with a matched null under the same resource budget. Do not tune parameters post hoc and then treat the new run as confirmatory.
