# E7 — Stability and Identity

This folder contains the exploratory abstract-network pilot for OMEGA-DNA.

- Research framing: `RESEARCH_STABILITY_IDENTITY_MIRROR_LIFE.md`
- Runner: `E7_STABILITY_IDENTITY_RUNNER.py`
- Results and limitations: `E7_STABILITY_IDENTITY_PILOT_RESULTS.md`

## Current status

Exploratory pilot executed for 40 seeds across four model conditions. This is not a preregistered confirmatory experiment and is not biological evidence. The main limitation is that the feedback condition receives the correct target labels directly. The next experiment must use common perturbation schedules, account for controller/resource costs, and include a less privileged maintenance rule.
