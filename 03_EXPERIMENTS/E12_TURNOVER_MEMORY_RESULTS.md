# E12 — Component Turnover and Memory Continuity

**Status:** exploratory simulation; not preregistered.  
**Date:** 2026-10-17  
**Runner:** [E12_TURNOVER_MEMORY_RUNNER.py](E12_TURNOVER_MEMORY_RUNNER.py)

## Question
Does preserving a node's historical trace across component replacement help a system retain its already encoded functional organization?

## Protocol
- 80 binary nodes; 200 steps; 100 paired seeds per condition.
- A balanced target pattern is used to initialize node states and construct a modular graph with 80% of each node's selected neighbors drawn from the same target class. This deliberately encodes the pattern in the topology.
- State noise: 0%, 1%, and 3% independent flips per node per step.
- Component turnover: 0%, 0.5%, 1%, and 3% independent node replacements per step. A replaced node's visible state is randomized; in the memory-preserved condition its local history trace remains associated with that functional position.
- Conditions: no memory; memory strength 2 with history preserved across replacement; matched memory strength 2 but history reset on replacement; stronger memory strength 4 with history reset on replacement.
- Memory trace decay: 0.8. Local-majority votes plus the memory term determine the next state; ties preserve the current state.
- Target labels are used only for graph construction, initialization, and evaluation, never by the state-update rule.
- Total: 3 noise levels × 4 turnover levels × 4 conditions × 100 seeds = 4,800 trials.
- Primary metric: fraction of nodes matching the target, averaged over all 200 steps. Paired comparisons use the same seed across conditions.

## Results at 3% state noise

| Component turnover per step | No memory | Memory strength 2, history preserved | Memory strength 2, history reset | Strong memory 4, history reset |
|---:|---:|---:|---:|---:|
| 0% | 95.40% | 98.70% | 98.70% | 98.27% |
| 0.5% | 94.87% | 98.19% | 98.10% | 97.45% |
| 1% | 94.65% | 98.18% | 98.03% | 94.56% |
| 3% | 92.02% | 98.14% | 96.50% | 83.93% |

At 3% noise and 3% turnover, the paired difference between memory strength 2 with history preserved and the matched-strength condition that resets history was **+1.65 percentage points** (approximate 95% CI: **+0.32 to +2.97 pp**). Against no memory, the difference was **+6.12 pp** (approximate 95% CI: **+3.38 to +8.86 pp**).

At 1% noise and 3% turnover, preserving history versus resetting it differed by **+1.43 pp** (approximate 95% CI: **+0.14 to +2.73 pp**). With no turnover, the preserved and reset conditions are identical by design.

The strong-memory condition (strength 4) performed worse as turnover increased. This is consistent with stale memory becoming a liability when the component state is replaced: more inertia is not always better.

## Interpretation
This model supports a narrow conclusion: when topology already encodes the target pattern, carrying a moderate historical trace across component replacement can improve pattern retention relative to resetting that trace. The effect is largest under the highest tested turnover and noise.

However, this does **not** demonstrate that a system spontaneously creates its own identity or that memory is universally necessary for life. The target pattern is encoded in the graph and initialization; the memory term is an explicit mechanism. The model's notion of replacement preserves the node's graph position and functional role, while randomizing its visible state. This is a specific abstraction of component turnover, not a realistic model of cell replacement.

## Limitations
- Exploratory and not preregistered.
- Target-aligned topology means this tests persistence of an encoded organization, not emergence.
- Memory is assigned to functional positions; whether real systems can transfer such history across component replacement is domain-specific.
- No energy/resource cost, edge turnover, alternative topology controls, or independent implementation audit.
- Raw trial-level CSV is generated by the runner but not committed in this commit.

## Decision
**Limited support** for the narrow hypothesis that continuity of local history helps preserve an already encoded organization under component turnover in this toy model. It is not evidence for a universal law or a biological mechanism.

## Next experiment
Pre-register a test where topology begins unaligned and adapts locally, with equal resource budgets and controls for stale memory. Test whether a functional pattern can emerge without target labels being encoded in either graph or controller.
